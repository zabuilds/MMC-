## Gate 9 — Launch decision

MMC is ready to move from construction into live operation only when the critical dependencies above are verified.

The launch decision should explicitly confirm:

**SERVICE READY + OPERATIONS READY + CAPACITY READY + FINANCIAL CONTROL READY + MANAGEMENT CONTROL READY + TECHNICAL FOUNDATION READY**

Legal work remains a separate required business gate and is intentionally outside this construction checklist.

## First-live-service test

The first real client journey should successfully demonstrate:

**PROSPECT → AGREEMENT → ONBOARDING → VESSEL BASELINE → SCHEDULE → ASSIGN → VISIT → FINDINGS → EVIDENCE → REPORT → COMMUNICATE → ACTION → VERIFY → COLLECT → RETAIN**

Any failure should be recorded, triaged, corrected, and incorporated into the appropriate operating or technical control.

## No-fake-readiness rule

A checkbox is not complete because a document exists.

A gate is complete only when the underlying capability has been verified at the appropriate level.

## Principle

MMC should not declare itself operational because the software looks finished. It should declare itself operational when the business can reliably deliver, document, communicate, collect, verify, and learn from real service.
