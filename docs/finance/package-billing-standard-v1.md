# Meridian Marine Co. — Package Billing Standard v1

## Purpose

Create a predictable billing structure for recurring MMC packages while keeping service scope and additional charges clear.

## Recurring packages

- Harbour — CI$225/month
- Steward — CI$395/month
- Reserve — CI$675/month
- Private — custom pricing

## Billing principles

- Package price covers only the defined recurring scope.
- Third-party costs are separate unless explicitly included in a written agreement.
- Material out-of-scope work requires approval before commitment where practical.
- Do not silently convert recurring add-on work into package obligations.
- Billing records should match the active client agreement.

## Package changes

Any upgrade, downgrade, pause, or custom arrangement should have an effective date and documented owner approval.

## Billing exceptions

Credits, refunds, discounts, or waived charges should be documented with a reason and approval authority.

## Failed payment handling

A failed payment should trigger a controlled administrative workflow rather than immediate service abandonment. Management should review the account, notify the owner appropriately, and determine whether service continues, pauses, or requires another arrangement.
