# Meridian Marine Co. — Vessel Onboarding Standard v1

## Purpose

Turn a new client and vessel into a clear, documented operating relationship before recurring service begins.

## Onboarding sequence

**WELCOME → PROFILE → AUTHORIZE → BASELINE → ACTIVATE → CONFIRM**

### Welcome
Confirm the service package, primary owner contact, expectations, communication preferences, and first-service timing.

### Profile
Create the vessel record with:

- Vessel name
- Vessel type/class
- Location/home marina
- Access arrangements
- Owner/contact details
- Emergency contacts
- Preferred vendors
- Existing service providers
- Known recurring issues
- Service history available to MMC
- Owner arrival/departure patterns where relevant
- Special instructions

### Authorize
Document:

- Selected package
- Included service scope
- Approved contacts
- Spending/coordination authority
- Emergency authority
- Access permissions
- Communication rules
- Add-on approval process

### Baseline
Conduct the first structured vessel assessment and establish the initial condition baseline. Existing defects should be documented so they are not incorrectly attributed to later MMC activity.

### Activate
Set recurring visit schedule, reporting cadence, open-action tracking, vendor contacts, and readiness requirements.

### Confirm
Send the owner a concise onboarding confirmation covering what MMC will do, what remains outside scope, current open items, and the next scheduled action.

## Onboarding principle

The vessel profile is the operational source of truth for recurring MMC service. Material changes should be updated rather than relying on memory or informal messages.
