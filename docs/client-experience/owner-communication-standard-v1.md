# Meridian Marine Co. — Owner Communication Standard v1

## Purpose

Make MMC communication calm, predictable, useful, and appropriate to the urgency of the situation.

## Communication hierarchy

### Critical
Immediate contact through the agreed emergency hierarchy. Do not wait for the routine report.

### Urgent
Prompt owner notification with the issue, evidence, recommended next step, and any decision required.

### Attention
Include in the scheduled report and follow through according to package scope.

### Monitor
Include when useful for continuity and future comparison.

## Routine communication

### Harbour
Concise scheduled report after each recurring visit.

### Steward
Enhanced report after each visit plus action updates when meaningful maintenance/service coordination occurs.

### Reserve
Premium report after each visit plus priority status updates for material open items and readiness activity.

## Communication standards

MMC communications should answer four questions quickly:

1. What did we observe?
2. How important is it?
3. What has been done or needs to happen?
4. What do we need from you, if anything?

## Owner preference profile

During onboarding, record:

- Preferred communication channel
- Preferred report format
- Normal response expectations
- Emergency contact hierarchy
- People authorized to receive updates
- Spending approval preferences
- Vendor preferences
- Arrival/departure notification preferences

## Boundaries

MMC should not overwhelm owners with low-value updates, use alarmist language, or represent third-party technical opinions as MMC findings.

When an owner decision is required, the decision should be explicit and easy to understand.
