# Meridian Marine Co. — Security Event & Audit Standard v1

## Security event categories

- Unauthorized access attempt
- Incorrect data exposure
- Lost/stolen access credential
- Suspicious account activity
- Unauthorized financial action
- Unauthorized vessel/property action
- Data integrity concern

## Response sequence

**DETECT → CONTAIN → ESCALATE → RECORD → INVESTIGATE → REMEDIATE → REVIEW**

## Audit requirements

Material operational and security events should retain enough information to establish:

- Actor/user
- Date/time
- Affected client/vessel
- Event/action
- Previous and resulting state where relevant
- Authorization context
- Resolution

## Access credential rule

Keys, access codes, credentials, and other sensitive access information should not be placed casually into general notes, reports, vendor messages, or client-visible records.

## Review principle

Security events and material audit exceptions should be reviewed by management and used to improve the operating system rather than treated as isolated incidents.
