# Meridian Marine Co. — Vendor Workspace & Coordination v1

## Purpose

Turn approved findings into controlled vendor work while keeping MMC responsible for oversight, communication, evidence, and closure.

## Assignment flow

**FINDING → SCOPE → OWNER APPROVAL IF REQUIRED → VENDOR SELECTED → ASSIGNED → ACKNOWLEDGED → IN PROGRESS → UPDATE → COMPLETED → VERIFIED → CLOSED**

## Vendor view

A vendor should see only what is required for the assignment:

- Vessel/work location as appropriate
- Work request
- Approved scope
- Relevant evidence
- Access/contact instructions required for the job
- Due date/priority
- Assignment status
- Required completion evidence

## MMC control

MMC retains control of:

- Scope definition within its coordination role
- Owner communication
- Approval tracking
- Vendor selection
- Assignment status
- Progress monitoring
- Completion evidence
- Verification
- Client reporting

MMC does not represent itself as the specialist performing or certifying technical work unless separately qualified and authorized to do so.

## Vendor communication

Requests should clearly state:

**WHAT → WHERE → PRIORITY → APPROVED SCOPE → REQUIRED RESPONSE → COMPLETION EVIDENCE**

## Failed or delayed work

If a vendor does not respond, misses a commitment, expands scope without authorization, or fails verification, the assignment moves into exception handling and may trigger backup-vendor activation.

## Closure rule

Vendor completion does not equal MMC closure. MMC closes the operational item only after the required evidence/verification and client communication steps are satisfied.
