# Meridian Marine Co. — Operator Workflow UI v1

## Interaction model

The interface should prioritize action over navigation.

### Start of day

**DASHBOARD → TODAY'S QUEUE → FIRST PRIORITY**

### Visit execution

**VISIT → CHECKLIST → FINDINGS → EVIDENCE → COMPLETE**

### Post-visit

**REPORT → QA → DELIVERY → ACTION QUEUE**

### Exception handling

**ALERT → FINDING → ESCALATE → ASSIGN → TRACK**

## Required interface behavior

- Clear current state
- Clear next action
- Minimal duplicate data entry
- Visible save/progress state
- Easy access to prior vessel history
- Strong visual distinction for critical/urgent items
- Confirmation before destructive actions
- No silent loss of work

## Mobile consideration

The field workflow should remain usable on a phone because operators may be working aboard vessels rather than at a desk.

## Principle

The operator should spend time observing vessels and managing outcomes, not fighting the software.
