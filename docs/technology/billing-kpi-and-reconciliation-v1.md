# Meridian Marine Co. — Billing KPI & Reconciliation v1

## Core billing KPIs

- Active recurring revenue
- Active vessels by package
- Billing success rate
- Failed/overdue payments
- Outstanding balances
- Credits/refunds/adjustments
- Revenue by package

## Service economics

- Revenue per vessel
- Direct service cost per vessel
- Contribution per vessel
- Operator time per vessel
- Vendor/coordination burden
- Contribution by package

## Reconciliation

Financial records should be reconciled between the operational system and payment system once payment processing is activated.

The reconciliation process should identify:

- Missing payment events
- Duplicate events
- Amount mismatches
- Unexpected status differences
- Unapplied credits/refunds
- Unrecognized charges

## Management rule

No financial dashboard should be considered authoritative until the underlying billing and operational records have passed reconciliation checks.
