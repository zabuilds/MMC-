# Meridian Marine Co. — Vendor Assignment Exception Workflow v1

## Exception triggers

- No acknowledgment
- Missed appointment
- Delayed response
- Scope dispute
- Unexpected cost
- Safety concern
- Incomplete work
- Failed verification
- Client dissatisfaction

## Response

**DETECT → ASSESS → COMMUNICATE → CORRECT/REASSIGN → VERIFY → CLOSE**

## Backup activation

Where the issue threatens service, safety, readiness, or client expectations, MMC may activate an approved backup vendor according to the contingency framework.

## Commercial boundary

Unapproved scope expansion or material cost changes require the appropriate client authorization before proceeding, except where an established emergency procedure permits immediate action.

## Performance record

Material vendor exceptions should feed the vendor performance record and may affect future assignment priority or vendor status.
