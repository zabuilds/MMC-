# Meridian Marine Co. — Security Readiness Checklist v1

## Access

- [ ] Roles defined
- [ ] Least-privilege permissions defined
- [ ] Client isolation defined
- [ ] Vendor isolation defined
- [ ] Administrative boundaries defined

## Data

- [ ] Sensitive data categories identified
- [ ] Retention expectations defined
- [ ] Audit requirements defined
- [ ] Evidence/report access boundaries defined

## Operational resilience

- [ ] Manual fallback process defined
- [ ] Emergency communication fallback defined
- [ ] Outage recovery priorities defined
- [ ] Reconciliation process defined

## Application readiness

- [ ] Authentication behavior validated
- [ ] Authorization behavior validated
- [ ] Invalid state transitions rejected
- [ ] Material changes audited
- [ ] Recovery tested

## Release gate

The system should not be treated as production-ready until the security, authorization, audit, and continuity controls have been tested against realistic operational scenarios.
