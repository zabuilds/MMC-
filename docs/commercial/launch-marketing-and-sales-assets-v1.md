# Meridian Marine Co. — Launch Marketing & Sales Assets v1

## Objective

Define the minimum asset set required to begin credible customer and partner outreach without waiting for the full technology stack.

## Core assets

1. One-page MMC service overview
2. Package comparison sheet
3. Client proposal template
4. First-vessel onboarding summary
5. Sample vessel report
6. Partner introduction sheet
7. Prospect qualification sheet
8. Sales conversation framework
9. FAQ / objection handling sheet
10. Client referral request framework

## Asset hierarchy

### Awareness

**Problem → MMC → Why independent oversight matters**

### Consideration

**How it works → Packages → Evidence/reporting → Boundaries → Trust**

### Decision

**Vessel needs → Recommended package → Price → Start date → Next step**

### Onboarding

**Welcome → Information → Access → Baseline → Activation**

## One-page overview requirements

Must communicate in under two minutes:

- Who MMC serves
- What problem MMC solves
- What MMC does
- Why independence matters
- Package structure
- What the owner receives
- How to begin

## Package comparison

Show the three standard packages without turning the comparison into a commodity price table. Emphasize service level, oversight cadence, readiness, and owner confidence.

## Proposal standard

Every proposal should be vessel-specific and include:

- Owner need
- Vessel
- Recommended service
- Included scope
- Boundaries/exclusions
- Reporting
- Price
- Start date
- Next action

## Sample report

The sample report should demonstrate the actual MMC experience using clearly identified demonstration content. It must never be presented as a real client record.

## Partner sheet

Give brokers, marinas, and marine professionals a concise explanation of:

- Who MMC is
- Which owners are a good fit
- What MMC handles
- What MMC does not handle
- How introductions work

## Outreach rule

Do not build a large advertising campaign before the first-client pilot produces evidence about which messages and customer profiles convert.

## Minimum launch principle

**Credibility before volume. Proof before scale.**
