# Meridian Marine Co. — Pilot Vessel Scorecard v1

## Service quality

- Visit completed to scope
- Evidence captured correctly
- Findings classified consistently
- Critical/Urgent issues escalated correctly
- Report delivered on standard
- Follow-up completed
- Closure verified

## Client experience

- Onboarding was clear
- Communication was timely
- Reports were understandable
- Client knew what action was required
- Client confidence increased
- Client would continue service
- Client would recommend MMC

## Operations

- Actual visit time
- Travel time
- Documentation/reporting time
- Follow-up time
- Vendor coordination time
- Exception count
- Overdue actions
- Rework required

## Economics

- Monthly recurring revenue
- Direct service cost
- Estimated contribution
- Capacity consumed
- Major cost drivers

## Learning

Record:

- Unexpected client needs
- Scope ambiguities
- Repeated operational friction
- Technology gaps
- Vendor weaknesses
- Package mismatches
- Opportunities for automation

## Pilot decision

Each vessel should conclude with:

**KEEP → MODIFY → STANDARDIZE → REMOVE → ESCALATE FOR REVIEW**
