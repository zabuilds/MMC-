# Meridian Marine Co. — First Client Sales Execution System v1

## Objective

Convert the first qualified prospects into paying vessels through a disciplined, owner-focused process.

## Sales sequence

**TARGET → INTRODUCE → QUALIFY → DISCOVER → FIT → PROPOSE → FOLLOW UP → CLOSE → ONBOARD**

## 1. Target

Prioritize prospects with a clear service fit rather than maximizing contact volume.

Strong indicators:

- Vessel in Cayman
- Owner frequently away
- Limited trusted local oversight
- Desire for independent visibility
- Recurring need rather than a one-time inspection

## 2. Introduce

The introduction should explain the outcome in simple terms:

MMC provides an independent local set of eyes on the vessel when the owner is away.

## 3. Qualify

Confirm:

- Vessel/location
- Owner presence/absence
- Current oversight
- Main concern
- Service frequency desired
- Decision-maker
- Timing
- Package fit

## 4. Discovery

Understand what uncertainty currently exists for the owner.

Key questions:

- What happens when you are away from the vessel?
- Who currently checks on it?
- How do you learn when something changes?
- What happens when a vendor needs to be involved?
- What would make you feel more confident about the vessel?
- What level of oversight would feel appropriate?

## 5. Fit

Recommend the package that best matches the owner's actual need.

Do not push the highest package automatically.

## 6. Proposal

Proposal includes:

- Owner need
- Vessel
- Recommended package
- Scope
- Boundaries
- Reporting
- Price
- Start date
- Clear acceptance step

## 7. Follow-up

Follow-up should be purposeful rather than repetitive.

Sequence:

**PROPOSAL → CLARIFY → HANDLE OBJECTIONS → CONFIRM DECISION → CLOSE/NURTURE**

## 8. Close

Once the client accepts:

- Confirm selected service
- Confirm start date
- Confirm billing method
- Initiate onboarding
- Create vessel record
- Schedule baseline/first service

## 9. Sales discipline

Do not:

- Pressure prospects
- Invent urgency
- Promise work outside scope
- Discount reflexively
- Misrepresent independence
- Treat every prospect as a fit

## Sales KPIs

Track:

- Prospects contacted
- Qualified prospects
- Discovery conversations
- Proposals
- Close rate
- Days to close
- New active vessels
- Recurring revenue
- Source of each win/loss

## First-client objective

The first sales cycle should produce both revenue and learning. Every meaningful objection, delay, and win should improve the next sales conversation.
