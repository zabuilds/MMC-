# Meridian Marine Co. — Client Service Review Framework v1

## Purpose

Create a repeatable review process that identifies retention risks and service improvements before a client becomes dissatisfied enough to leave.

## Review questions

1. Is MMC delivering the promised service consistently?
2. Is communication clear and timely?
3. Are findings and reports useful to the owner?
4. Are vendor issues being coordinated effectively?
5. Has the vessel's needs changed?
6. Does the current package still fit?
7. Is there any unresolved concern?
8. Would the client confidently recommend MMC?

## Outcomes

**HEALTHY → IMPROVEMENT REQUIRED → AT RISK → RECOVERY**

## Recovery

For an at-risk client:

**LISTEN → IDENTIFY ROOT CAUSE → CORRECT → CONFIRM SATISFACTION → MONITOR**

## Management use

Service review patterns should feed back into SOPs, package design, staffing, vendor selection, and pricing decisions.
