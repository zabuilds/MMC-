# Meridian Marine Co. — First Vessel Activation Standard v1

## Activation gate

A vessel may move to ACTIVE service when:

- Client relationship is confirmed
- Package and start date are confirmed
- Required vessel information is complete
- Access arrangements are verified
- Communication path is confirmed
- Initial service plan is established
- Baseline visit is scheduled or completed according to the onboarding plan
- Known limitations are recorded

## Initial baseline

The first visit should establish a practical reference point for:

- General condition
- Readiness
- Security/access observations
- Visible maintenance concerns
- Equipment/area observations within MMC scope
- Existing open issues
- Immediate follow-up needs

## Activation outcome

The vessel should finish activation in one of these states:

**ACTIVE → ACTIVE WITH OPEN ACTIONS → ONBOARDING INCOMPLETE → HOLD**

## Owner communication

The client should receive confirmation that the vessel is active, the next planned service event, and any material issues requiring attention.

## Principle

Activation is not merely an administrative status. It means MMC has enough verified information and an agreed operating plan to begin delivering the promised service responsibly.
