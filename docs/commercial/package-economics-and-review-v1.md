# Meridian Marine Co. — Package Economics & Review v1

## Package review

MMC should periodically compare each package against actual operating load rather than assuming the original pricing remains optimal.

Review:

- Visits per vessel
- Average visit duration
- Travel/access burden
- Reporting time
- Client communication load
- Vendor coordination load
- Emergency/event frequency
- Direct costs
- Gross margin

## Package decisions

A package may be:

- Retained
- Repriced for new clients
- Redesigned
- Restricted to clearer scope
- Upgraded/downgraded for a client
- Replaced by a custom arrangement

## Pricing discipline

Existing client pricing should not be changed casually. Any pricing change should consider contractual terms, client communication, service scope, and transition timing.

## Management trigger

If a package consistently produces materially more workload than its commercial assumptions support, management should address scope, pricing, process efficiency, or client fit rather than allowing margin erosion to become normal.
