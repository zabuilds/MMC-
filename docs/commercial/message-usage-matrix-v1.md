# Meridian Marine Co. — Message Usage Matrix v1

| Audience | Primary message | Desired outcome |
|---|---|---|
| Vessel owner | Independent local oversight when you are away | Discovery |
| Warm prospect | Confidence and visibility without full management | Conversation |
| Yacht broker | A trusted oversight resource for clients who are away | Introduction |
| Marina | Independent owner-side visibility and coordination | Relationship |
| Marine vendor | Clear, professional coordination without role confusion | Cooperation |
| Existing client | We are watching, documenting, alerting, and following through | Confidence |
| At-risk client | We heard the concern and are correcting the root issue | Recovery |
| Referral prospect | A trusted local presence for the vessel | Discovery |

## Universal communication structure

**CONTEXT → OBSERVATION → IMPACT → ACTION → NEXT STEP**

## Tone guardrail

The message should feel composed and accountable, never dramatic or pushy.
