# Meridian Marine Co. — First 100 Prospect Acquisition Plan v1

## Objective

Build an initial qualified prospect pipeline without outrunning service capacity.

## Prospect groups

### Group A — Warm network
Existing relationships, introductions, trusted marine contacts, and personal/business networks.

### Group B — Professional referral network
Marinas, brokers, captains, marine vendors, yacht professionals, and related trusted advisors.

### Group C — Targeted owner outreach
Qualified vessel owners whose profile suggests a recurring oversight need.

## Prospect record

Track:

- Prospect name
- Vessel
- Location
- Source
- Qualification status
- Primary need
- Discovery status
- Proposal status
- Next action
- Estimated service fit

## Batch approach

Work in small prospect batches, review conversion quality, then adjust the next batch.

### Batch 1
Build and qualify the first 20 prospects.

### Batch 2
Add 20 more based on the strongest-performing source patterns.

### Batch 3
Add 20 more while testing referral and direct outreach balance.

### Batch 4
Add 20 more and refine qualification.

### Batch 5
Complete the first 100 and assess conversion, capacity, and acquisition economics.

## Success measure

The goal is not 100 names. The goal is a healthy pool of qualified prospects that MMC can realistically convert and serve at its promised standard.
