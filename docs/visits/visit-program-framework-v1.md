# Meridian Marine Co. — Vessel Visit Program Framework v1

## Purpose

Define a consistent field-service system across Harbour, Steward, and Reserve without confusing package scope.

## Universal visit flow

**PREPARE → ARRIVE → SECURE → OBSERVE → DOCUMENT → ACT → REPORT → CLOSE**

### Prepare
Review vessel record, previous visit, open actions, vendor activity, owner instructions, and weather/access conditions.

### Arrive
Confirm authorized access and arrival condition.

### Secure
Perform appropriate basic safety/security checks before beginning the observation.

### Observe
Inspect visible and reasonably accessible areas within MMC's agreed scope.

### Document
Capture relevant observations with clear notes and appropriate evidence.

### Act
Escalate Critical/Urgent findings and create follow-up actions when appropriate.

### Report
Prepare the appropriate owner-facing visit report.

### Close
Confirm access/security status, update outstanding actions, and close the visit record.

## Common observation areas

- Exterior condition
- Interior condition
- Visible water intrusion
- Bilge/general water condition where safely accessible
- Power/electrical indicators where safely observable
- HVAC/refrigeration indicators where applicable
- Plumbing/water indicators where safely observable
- Security/access condition
- Visible storm/weather impact
- Unusual odors/noises/conditions
- Owner-specific instructions

## Boundary

MMC observes, documents, alerts, and coordinates. The visit is not a substitute for specialist inspection, engineering, mechanical diagnosis, survey, or repair work.
