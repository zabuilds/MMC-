# Meridian Marine Co. — Visit Report Template Standard v1

## Report structure

### 1. Visit summary

- Vessel
- Date/time
- Visit type
- Operator
- General condition summary

### 2. Condition overview

Summarize notable observations across:

- Exterior
- Interior
- Water/bilge indicators
- Security
- Visible systems indicators
- Presentation/readiness
- Weather/storm impacts

### 3. Findings

For each material finding:

- Title
- What was observed
- Location
- Severity
- Evidence reference
- Recommended next step

### 4. Actions

Identify actions created, responsible party, due date, approval state, and current status.

### 5. Vendor activity

Record relevant vendor work requested, scheduled, completed, or awaiting follow-up.

### 6. Owner attention

Clearly identify matters requiring owner decision, approval, or awareness.

### 7. Closeout

State whether the visit is complete, whether follow-up remains open, and the next expected visit/action.

## Report language

Reports should be factual, calm, concise, and useful. Distinguish clearly between observed conditions, vendor statements, owner instructions, and MMC recommendations.
