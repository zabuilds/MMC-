# Meridian Marine Co. — Weekly Operations Review v1

## Purpose

Create a recurring management rhythm for service quality, workload, risks, and network capacity.

## Review areas

### Client service
- Active clients
- Visits completed
- Missed/limited visits
- Open Critical/Urgent findings
- Aging actions
- Client requests
- Approval bottlenecks

### Vessel readiness
- Upcoming arrivals/departures
- Readiness tasks
- Blocked readiness items

### Vendors
- Active jobs
- Vendor delays
- Service failures
- Preferred vendor performance
- Coverage gaps

### Emergency/storm
- Recent events
- Open recovery actions
- Unresolved damage
- Emergency network readiness

### Capacity
- Upcoming workload
- Operator availability
- Vendor capacity
- High-risk schedule conflicts

## Review outcomes

Every material issue should result in one of:

- Continue
- Assign
- Escalate
- Reprioritize
- Approve
- Close
- Create improvement task

## Management principle

The weekly review should identify problems before they become client-visible failures.
