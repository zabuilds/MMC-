# Meridian Marine Co. — Package Visit Checklists v1

## Shared pre-visit checklist

- [ ] Confirm vessel and location.
- [ ] Confirm scheduled visit window.
- [ ] Review previous unresolved findings.
- [ ] Review owner instructions and current access information.
- [ ] Check weather/storm conditions when relevant.
- [ ] Confirm any approved vendor/service activity expected during the visit.
- [ ] Confirm safe access before arrival.

## Harbour visit checklist

### Visit objective
Complete the baseline vessel oversight visit and identify material conditions.

- [ ] Confirm vessel access.
- [ ] Exterior visual walk-through.
- [ ] Interior visual walk-through of agreed accessible areas.
- [ ] Observe obvious signs of leaks, water intrusion, damage, unusual odors, pests, or security concerns.
- [ ] Observe agreed visible equipment/status indicators without specialist testing.
- [ ] Compare material observations against prior visit where applicable.
- [ ] Photograph noteworthy findings.
- [ ] Classify findings.
- [ ] Escalate material issues.
- [ ] Complete concise owner report.
- [ ] Record follow-up item if coordination is required.

## Steward visit checklist

### Visit objective
Maintain recurring oversight while actively supporting routine vessel care.

Complete the Harbour checklist, plus:

- [ ] Review all open maintenance/service items.
- [ ] Check status of previously coordinated vendors.
- [ ] Confirm expected service appointments.
- [ ] Review visible condition of agreed readiness areas.
- [ ] Check pre-arrival requirements when applicable.
- [ ] Coordinate approved routine services.
- [ ] Update maintenance follow-up tracker.
- [ ] Record vendor/service status.
- [ ] Identify items that should be addressed before the next scheduled visit.
- [ ] Deliver enhanced report with open-action status.

## Reserve visit checklist

### Visit objective
Provide the highest standard recurring oversight and proactive readiness support.

Complete the Steward checklist, plus:

- [ ] Review the full open-action and maintenance picture.
- [ ] Conduct weekly condition comparison against prior observations.
- [ ] Review upcoming owner arrival/departure requirements.
- [ ] Confirm readiness-critical vendor/service activity.
- [ ] Prioritize unresolved material items.
- [ ] Provide priority coordination where included.
- [ ] Review storm/event readiness when relevant.
- [ ] Confirm priority follow-up status.
- [ ] Record expanded vessel condition notes.
- [ ] Deliver premium report with action priorities and outstanding risks.

## Pre-arrival readiness checklist

When included in Steward or Reserve, or purchased as an add-on:

- [ ] Confirm owner arrival date/time.
- [ ] Confirm requested vessel configuration.
- [ ] Confirm approved vendors and scheduled services.
- [ ] Confirm fueling/service requirements.
- [ ] Confirm access and marina coordination.
- [ ] Verify agreed readiness items have been completed by responsible parties.
- [ ] Document outstanding items.
- [ ] Escalate anything that could materially affect arrival readiness.
- [ ] Send readiness status to owner.

## Post-service verification

MMC verifies completion at the level reasonably observable and within its role. Verification is not a technical certification or guarantee of vendor workmanship.

- [ ] Confirm vendor/service attendance.
- [ ] Confirm reported work or service occurred.
- [ ] Capture relevant evidence when useful.
- [ ] Record unresolved items.
- [ ] Update action status.
- [ ] Notify owner of material exceptions.

## Visit closeout checklist

- [ ] All findings classified.
- [ ] Critical/urgent items escalated.
- [ ] Follow-up actions recorded.
- [ ] Vendor coordination recorded where applicable.
- [ ] Report completed.
- [ ] Evidence stored according to MMC records procedure.
- [ ] Next required action/date identified.
