# Meridian Marine Co. — Management Review Cadence v1

## Daily review

Review:
- Today's visits
- Critical/Urgent issues
- Owner arrival/departure readiness
- Vendor appointments
- Access/weather constraints
- Unassigned tasks

## Weekly review

Review:
- Active vessels and visit completion
- Open maintenance actions
- Vendor performance issues
- Upcoming owner arrivals
- Storm/event exposure
- Client communication issues
- Incident records
- Service quality exceptions
- Capacity/workload

## Monthly review

Review:
- Active clients by package
- Revenue by package
- Visit volume
- Time spent per client
- Coordination workload
- Unplanned work
- Vendor costs/pass-through activity
- Client retention/feedback
- Acquisition source
- Package profitability indicators
- Operational incidents
- SOP/process changes required

## Management principle

Review data should drive decisions about pricing, package boundaries, staffing, service quality, client selection, and growth. Do not scale a process that cannot be measured or reliably delivered.
