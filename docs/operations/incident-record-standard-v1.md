# Meridian Marine Co. — Incident Record Standard v1

## Purpose

Create an auditable record whenever an event materially affects safety, vessel condition, security, service delivery, or MMC operations.

## Incident record

Record:

- Vessel/client
- Date/time
- Location
- What occurred
- How it was discovered
- Initial classification
- Immediate actions
- People/organizations contacted
- Owner communication
- Vendor/emergency response
- Evidence references
- Current status
- Remaining risk
- Next action
- Closure date/outcome

## Incident categories

- Vessel condition
- Storm/weather
- Water intrusion
- Fire/safety
- Security/access
- Vendor/service failure
- Client communication
- MMC operational error
- Other material event

## Response rule

Safety and immediate risk take priority over documentation. Complete the record after urgent conditions are controlled.

## Review

Material incidents should be reviewed by MMC management to identify preventable causes, communication failures, process gaps, or required SOP changes.
