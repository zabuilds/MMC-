# Meridian Marine Co. — Internal Daily Work Queue v1

## Purpose

Give MMC operators one prioritized view of everything that requires attention.

## Queue priorities

### P0 — Emergency
Critical safety, vessel, security, storm, or property matters requiring immediate action.

### P1 — Urgent
Time-sensitive owner decisions, urgent findings, vendor failures, readiness blockers, or overdue material actions.

### P2 — Scheduled
Today's planned visits, vendor coordination, approved service requests, reports, and readiness tasks.

### P3 — Follow-up
Open actions, routine client communication, vendor reviews, administrative work, and upcoming planning.

### P4 — Planning
Future visits, preventive work, network development, relationship management, and improvement tasks.

## Queue item minimum

Every actionable item should show:

- Client/vessel
- Task
- Priority
- Owner
- Due date/time
- Status
- Approval requirement
- Related finding/request/vendor
- Next action

## Daily operating rhythm

**REVIEW → PRIORITIZE → EXECUTE → UPDATE → ESCALATE → CLOSE**

No task should remain indefinitely in an ambiguous state. If blocked, record why and what is required to move it forward.
