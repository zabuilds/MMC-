# Meridian Marine Co. — KPI Framework v1

## Purpose

Measure whether MMC is delivering reliable service, protecting client trust, and operating efficiently.

## Client service KPIs

- Active clients
- Active vessels
- Visits completed on schedule
- Visit completion rate
- Report delivery timeliness
- Client requests resolved
- Client retention

## Operational KPIs

- Open Critical/Urgent findings
- Average action age
- Overdue actions
- Blocked work items
- Readiness requests completed on time
- Emergency response events
- Repeat service failures

## Vendor KPIs

- Preferred vendor coverage by category
- Backup coverage by category
- Vendor response reliability
- Vendor completion reliability
- Vendor service failures
- Invoice discrepancies

## Commercial KPIs

- Monthly recurring revenue
- Revenue by package
- Revenue concentration
- Average revenue per vessel
- Vendor/service coordination costs
- Gross margin by service type

## Experience KPIs

- Client response time
- Approval turnaround time
- Client complaints
- Client satisfaction/review signals
- Escalations per active vessel

## KPI principle

Metrics should drive decisions. MMC should avoid measuring activity merely for the appearance of performance.
