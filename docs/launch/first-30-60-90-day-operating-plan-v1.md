# Meridian Marine Co. — First 30/60/90 Day Operating Plan v1

## Days 0–30 — Controlled Launch

Focus on reliability over volume.

- Activate first clients/vessels carefully
- Establish vessel baselines
- Run recurring visit/report cycle
- Validate emergency response
- Test vendor coverage
- Capture quality exceptions
- Review every operational failure

## Days 31–60 — Stabilize

- Refine visit/report workflows
- Review client communication cadence
- Measure package workload
- Review vendor performance
- Tighten queue priorities
- Identify recurring operational bottlenecks
- Begin structured referral activity

## Days 61–90 — Optimize

- Review retention and client feedback
- Review package economics
- Expand qualified vendor coverage
- Improve automation/system controls
- Formalize management dashboard rhythm
- Determine safe capacity for additional clients
- Prioritize the next product/service improvements

## Growth rule

Do not use early sales volume as the primary measure of success. The first 90 days should prove that MMC can consistently deliver the promised service before aggressively increasing client volume.
