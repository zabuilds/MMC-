# Meridian Marine Co. — Client & Vessel Baseline Standard v1

## Purpose

Create a reliable starting record so future MMC observations can be compared against an established baseline.

## Client baseline

Record:

- Client identity
- Communication preference
- Primary/secondary contacts
- Emergency contacts
- Approval/authorization expectations
- Owner priorities
- Arrival/departure patterns where relevant

## Vessel baseline

Record:

- Vessel name/type
- Location/marina
- Access method
- Known condition
- Known recurring issues
- Visible equipment/system notes within MMC scope
- Security/access instructions
- Special instructions
- Existing vendors
- Storm instructions
- Initial photographic/evidence record where appropriate

## Baseline findings

Distinguish clearly between:

- Existing known condition
- Newly observed condition
- Owner-reported condition
- Vendor-reported condition
- Condition requiring specialist assessment

## Baseline acceptance

The baseline should be reviewed for completeness before recurring service begins. Material gaps should be recorded rather than silently assumed.
