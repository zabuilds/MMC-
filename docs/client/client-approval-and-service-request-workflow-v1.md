# Meridian Marine Co. — Client Approval & Service Request Workflow v1

## Service request flow

**REQUEST → CLARIFY → SCOPE → AUTHORIZE → SCHEDULE → EXECUTE → REPORT → CLOSE**

## Request intake

Capture the client's request, vessel, desired timing, instructions, and any relevant constraints.

## Clarify

Confirm what MMC can coordinate directly and what requires a qualified third party.

## Scope

Define the requested work, expected outcome, and any known cost or timing information.

## Authorization

Determine whether the request is:

- Included in the client's package
- Covered by existing authority
- Requires owner approval
- Requires separate quotation/agreement
- Outside MMC scope

## Schedule

Coordinate the appropriate vendor/service and confirm timing.

## Execute

Track the work and record material changes.

## Report

Confirm status, outcome, unresolved issues, and cost information where relevant.

## Close

Close only when the request is complete or clearly transferred into an open action with an identified next step.

## Approval principle

MMC should never imply owner authorization that has not actually been granted. When authority is unclear, pause the non-emergency expenditure or scope expansion until clarified, unless a documented emergency provision applies.
