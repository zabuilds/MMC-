# Meridian Marine Co. — Client Request Status & Approval States v1

## Request lifecycle

**NEW → REVIEWING → AWAITING APPROVAL → AUTHORIZED → SCHEDULED → IN PROGRESS → COMPLETED → CLOSED**

## Alternate states

- **NEEDS CLARIFICATION** — required information is missing.
- **DECLINED** — owner or MMC has declined the requested work.
- **BLOCKED** — work cannot proceed because of access, vendor, safety, authorization, or another material constraint.
- **CANCELLED** — request withdrawn before completion.

## Approval rules

A request must not move to Authorized unless the required approval has actually been recorded.

Approval should identify:

- Approver
- Date/time
- Approved scope
- Approved amount or spending limit where applicable
- Relevant conditions

## Emergency exception

Documented emergency authority may allow immediate action when delay could materially worsen vessel/property risk. The reason, action, authority, and resulting cost must be recorded afterward.

## Closeout rule

A request is not Closed merely because a vendor says the work is finished. MMC should record completion evidence or the remaining limitation and next action.
