# Meridian Marine Co. — Client Report Experience v1

## Report hierarchy

### Executive view

Start with:

- Overall vessel status
- Key changes since last visit
- Critical/Urgent matters
- Actions required
- Readiness summary

### Detailed findings

Then provide supporting observations, evidence, locations, severity, and recommended next steps.

### Follow-up

Show each material action with:

- Current status
- Responsible party
- Due date where applicable
- Latest update
- Verification state

## Design principle

The report should answer three questions quickly:

**Is my vessel okay? What changed? What do I need to do?**

## Evidence

Evidence should be presented near the observation it supports rather than separated into an unstructured media dump.

## Limitations

Important limitations or inaccessible areas should be clearly stated so the report does not imply coverage that did not occur.
