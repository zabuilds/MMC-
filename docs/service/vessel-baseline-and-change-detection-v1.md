# Meridian Marine Co. — Vessel Baseline & Change Detection v1

## Purpose

Make recurring oversight more valuable by comparing current observations against a known vessel baseline.

## Baseline creation

At initial onboarding, establish where practical:

- Vessel identity and location
- Access arrangements
- Normal visible condition
- Known existing defects
- Key owner instructions
- Known vendor work
- Readiness expectations
- Important system indicators that MMC is authorized to observe
- Existing evidence supporting known conditions

## Change detection

Each recurring visit should consider:

**WHAT WAS NORMAL → WHAT CHANGED → HOW MATERIAL IS IT → WHAT ACTION IS REQUIRED**

## Change categories

- New condition
- Worsening condition
- Improved/resolved condition
- Recurring condition
- Expected change
- Unexplained change

## Reporting

Reports should distinguish between:

- Newly observed
- Previously documented/open
- Resolved since prior visit
- Monitoring

## Baseline limitation

A baseline is an operational reference, not a guarantee that every concealed or technical condition is known. MMC should clearly identify the limits of observation.
